# Mangen - Directory Manifest Generator

Утилита для генерации манифеста каталога в стиле UNIX-программ. Создает список файлов с их SHA-256 хеш-суммами.

## Установка

### Требования
- Компилятор C (gcc/clang)
- OpenSSL (для хеширования)
- Doxygen (для документации)
- Make

### Ubuntu/Debian
`sudo apt install build-essential libssl-dev doxygen`

## Особенности

- Рекурсивный обход директорий
- end-to-end тесты и возможность их запуска через `make tests`
- Реализована обработка опции `-e [FILE_NAME]`, исключающей из обработки все файлы/каталоги с именем `FILE_NAME`
- `FILE_NAME` может быть руглярным выражением с обработкой `. (точка)` как произвольного символа и `* (астериск)` как произвольной последовательности символов
- Добавлен вывод `git commit hash` при обработке опции `-v`
- Алгоритм хэширования SHA-256
- Генерация документации с ипользованием Doxygen

## Основные команды Makefile

```bash
# Сборка проекта (по умолчанию)
make

# Полная пересборка с очисткой
make rebuild

# Очистка артефактов сборки
make clean

# Запуск всех тестов
make tests

# Генерация документации (Doxygen)
make docs
```
